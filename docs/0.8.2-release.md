# Xenon360 v0.8.2 - Ghidra 12.1.4 and 12.2

Xenon360 v0.8.2 provides separate extension packages for stock Ghidra 12.1.4 and 12.2. It includes XEX/XEXP loading, the Xenon PowerPC/VMX128 language, import naming, native PDB/XDB support, and automatic analysis without a modified Ghidra installation, proprietary SDK, repair script, or network service.

## Changes since v0.7.0

- Automatic compiler-helper modeling and bounded recovery of supported read-only byte and unsigned-halfword relative switch tables.
- Native VMX128 p-code improvements, including corrected `lvrx128` memory behavior and integer lane semantics for `vpermwi128` and `vrlimi128`.
- Validated Havok metadata recognition and conservative recovery of unowned callbacks, with established names and function ownership preserved. Callback naming remains an explicit opt-in.
- Local analysis-evidence export and review-only reference comparison using native Ghidra BSim features when available. Candidate names, layouts and prototypes are never transferred automatically.
- Cancellable, repeatable analysis and deterministic packaging with synthetic regression receipts and public-safety checks.

## Choose the matching package

| Ghidra | Required JDK | Package |
|---|---|---|
| 12.1.4 | 21 | `ghidra_12.1.4_XenonVMX128_0.8.2.zip` |
| 12.2 | 25 | `ghidra_12.2_XenonVMX128_0.8.2.zip` |

The packages are not interchangeable. Verify the SHA-256 value against `SHA256SUMS.txt` or the package's `.sha256` file before installing. In PowerShell, use `Get-FileHash -Algorithm SHA256 <package.zip>`; on Linux use `sha256sum -c SHA256SUMS.txt` after downloading all listed assets, or `sha256sum <package.zip>` for one file. On macOS, use `shasum -a 256 <package.zip>`.

Back up existing projects and retain their original extension packages. Close open programs, remove the old XenonVMX128 extension through **File > Install Extensions**, and restart Ghidra. Install the matching v0.8.2 ZIP through the same dialog and restart again. Validate with a fresh import or a copy of a project. Never reopen a project migrated by 12.2 in 12.1.4.

Import an authorized executable using **Xenon360 XEX**, run normal Auto Analysis, and enable **XenonAnalysisPlugin** if prompted. Evidence actions are available under **Tools > Xenon360**. See the bundled README for loader options, limits and troubleshooting.

## Qualification and limits

Synthetic qualification checks parser and patch behavior, import names, language preparation, native VMX p-code, bounded switches, cancellation rollback, idempotency, symbols and function ownership. Two independent builds for each target must produce byte-identical ZIPs, and release qualification requires explicit passing receipts. Windows local qualification and Linux CI are separate evidence; a workflow configuration or successful process exit alone does not establish either result.

Opaque VMX floating-point fusion, estimates, saturation and compare-record semantics remain incomplete. Unsupported switch shapes and writable tables remain outside bounded recovery. Havok metadata identifies retained structures; it does not establish an exact linked SDK build or full object layout. Comparisons remain candidates for review.

These checks do not establish user visual acceptance or execution on physical Xbox 360 hardware. macOS has not been qualified.

## Source and reproduction

`xenon360-v0.8.2-source.zip` contains the release source and notices without Git history. With the matching Ghidra/JDK pair, run `gradlew.bat --no-daemon buildExtension smokeTest` on Windows or `./gradlew --no-daemon buildExtension smokeTest` on Linux, setting `JAVA_HOME` and `GHIDRA_INSTALL_DIR` first. Repeat in a second fresh directory with the same toolchain and compare ZIP bytes and SHA-256 values. The source README contains full build instructions.

## Rollback

Close programs, mark XenonVMX128 for removal in **File > Install Extensions**, and restart. Reinstall the retained package for the original Ghidra version and restart again. Restore an unmodified project backup; uninstalling an extension does not undo saved analysis or a language migration. The previous official v0.7.0 package targets Ghidra 12.1.4 only.
