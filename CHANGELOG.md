# Changelog

## 0.8.3

- Improved Xbox 360 vector and floating-point instruction support.
- Expanded automatic control-flow and switch recovery.
- Improved decompiler accuracy and consistency.
- Updated the Xenon processor language to version 1.4.
- Improved support for Ghidra 12.2 and 12.1.4.

See the release notes for known limitations and ongoing development.

## 0.8.2

- Expanded automatic switch recovery while preserving existing analysis.
- Added separate packages for Ghidra 12.1.4 / JDK 21 and Ghidra 12.2 / JDK 25.
- Improved release packaging and compatibility checks.

## 0.8.1

- Corrected vector instruction decoding and memory handling.
- Improved vector operations while preserving existing analysis and symbols.

## 0.8.0

- Added Ghidra 12.2 support.
- Added automatic compiler-helper analysis, switch recovery, Havok metadata recognition, and reference comparison.
- Improved extension packaging and regression coverage.
